# Investment archive implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Убрать обнулённые инвестсчета из текущих и показать понятные результаты в архиве.
**Architecture:** Архив вычисляется из invValueAt без изменения данных; общий helper денежных потоков используется активными и архивными карточками.
**Tech Stack:** Vanilla JS / HTML, Puppeteer.
**Spec:** docs/superpowers/specs/2026-11-06-investment-archive.md

## Global Constraints
- Весь JS и разметка в index.html, без зависимостей и изменений CSS.
- История, отложенные переводы, экспорт и синхронизация продолжают видеть все живые записи.
- fmtH для сумм, esc для названий; uiGet/uiSet для раскрытия архива.

## Review Focus
- Старые нулевые счета автоматически видны в архиве.
- Отрицательный остаток нельзя скрывать в архив.
- История и ожидающий банковский перевод не меняются из-за архива.
- Пополнение архивного счёта возвращает его в текущие.
- Нет годовой ставки архива и отрицательной подписи внесённой суммы.
