# Investment withdrawals implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Надёжный вывод и редактирование сумм инвестсчёта.
**Architecture:** Числовые snapshots сохраняются; snapshotContribs задаёт состав операций на дату снимка. Существующие модалки переиспользуются для исправления сумм.
**Tech Stack:** Vanilla JS / HTML, Puppeteer.
**Spec:** docs/superpowers/specs/2026-11-06-investment-withdrawals.md

## Global Constraints
- Весь JS и HTML в index.html, без новых зависимостей.
- Суммы сохраняются до копеек. История и доходность сохраняются.
- Протокол Apps Script не меняется. Публикация и коммит не входят в задачу.

## Review Focus
- Старые снимки без метаданных не должны неожиданно менять стоимость.
- Повторное обновление стоимости не должно дважды учитывать вывод.
- Исправление и удаление операций должны корректно менять банк.
- Пустое поле не равно нулевой стоимости; ноль допустим.
- Более поздние абсолютные снимки остаются авторитетными.
