# Доходность вкладов — архив закрытых + средняя доходность за период

Дата: 2026-09-12 · целевая версия v1.75.0

## Задача

Видеть, сколько рублей принесли вклады и какая у них средняя годовая доходность — за год,
за 12 месяцев и за всё время. Показывается в годовом отчёте и на странице вкладов.

## Проблема данных

Закрытие (`confirmCloseDeposit`) и удаление (`deleteDeposit`) сейчас неотличимы — оба ставят
`_deleted:true`, а `loadDB()` стирает тумбстоуны старше 90 дней. Через три месяца от закрытого
вклада не остаётся ни тела, ни дат, и доходность за год посчитать не из чего.

## 1. Данные

Новые поля вклада:
- `closedAt: 'YYYY-MM-DD'` — дата закрытия. `_deleted:true` остаётся: все существующие фильтры
  (списки, прогноз, Excel, «Всего активов») уже пропускают такие вклады.
- `closedInterest: number` — фактические проценты при закрытии (то, что пришло на счёт).
  Отдельное поле, а НЕ `finalAmount`: тот означает сумму на `endDate` и пересчитывает ставку,
  досрочное закрытие его бы испортило.

Правила:
- 90-дневная чистка тумбстоунов пропускает вклады с `closedAt`.
- `_depDelDay(d)` возвращает `closedAt`, если он есть (иначе — прежний локальный день `updatedAt`).
  Вклад, внесённый и закрытый задним числом, уходит из ряда активов в дату закрытия.
- Миграция `_migrateClosedDeposits()` в `loadDB()` ДО чистки: тумбстоун без `closedAt`, для
  которого есть живой доход с `source === 'Проценты по вкладу ' + d.name`, получает
  `closedAt = inc.date`, `closedInterest = inc.amount`, `updatedAt = Date.now()`. Идемпотентна.
- Синк не меняется: поля обычные, мерж LWW по `updatedAt`.

## 2. Модалка «Закрыть вклад»

Добавляются поля:
- «Дата закрытия» — по умолчанию `min(endDate, today)`, `max=today`, не раньше `openDate`.
- «Проценты» — предзаполнено `depositValueAt(d, дата) − тело − пополнения≤дата`, редактируемо;
  пересчитывается при смене даты, пока пользователь не правил поле руками.
- Галка «Записать проценты в доходы» (вкл. по умолчанию); тег-селект виден только при включённой
  галке и процентах > 0. Доход датируется датой закрытия.

`confirmCloseDeposit` пишет `closedAt`, `closedInterest`, `_deleted:true`, `updatedAt`.

## 3. Расчёт — `_depYield(from, to)` (в `═══ assets.js ═══`)

Период полуоткрытый `[from, to)`. Для каждого вклада с `openDate`, не удалённого без `closedAt`:
- `end` = `closedAt` || `endDate`.
- `I` (доход за жизнь): закрытый — `closedInterest`; открытый — `depositValueAt(d, endDate) − тело − пополнения`.
- `CD(a, b)` — деньго-дни: тело × дни пересечения `[openDate, end)` с `[a, b)` + каждое пополнение
  (с датой < end) × дни пересечения `[c.date, end)` с `[a, b)`.
- `CD_total = CD(openDate, end)`.
- **Начислено** = `I × CD(from, min(to, today+1)) / CD_total` (у будущего — не начисляем).
- **Получено** = `I`, если `closedAt ∈ [from, to)`, иначе 0.
- **Доходность вклада** = `I / (CD_total/365)`.

Итог: `{accrued, received, rate, rows:[{d, accrued, received, rate, closed}]}`, где
`rate = Σaccrued / (ΣCD_period/365)` — средневзвешенная годовая; `null`, если `ΣCD_period = 0`.
В `rows` — вклады с ненулевым `CD_period` или `received`.

## 4. Интерфейс

**Годовой отчёт** (`renderReport`, в `#rep-col-a` после карточки активов): карточка «Вклады» —
«Начислено X · Получено Y · ⌀ Z% годовых», ниже строки вкладов (название, `open–end`, ставка
вклада, начислено за период). Период: год → `[yyyy-01-01, yyyy+1-01-01)`, «всё время» →
`['0000', '9999')`. Нет строк — карточки нет.

**Страница вкладов:**
- Карточка «Доходность» с чипами «12 мес / этот год / всё» (`uiGet/uiSet('depYieldPeriod')`,
  по умолчанию `'year'`) — те же цифры и строки.
- Секция «Закрытые вклады» (`#deposits-closed-list`), новые сверху: название, `open → closedAt`,
  тело, `+closedInterest`, доходность. Тап → `openDepositModal(id)`.
- В модалке вклада для закрытого: видны поля «Дата закрытия» и «Проценты при закрытии»;
  `saveDeposit` сохраняет их и НЕ сбрасывает `_deleted`. «Удалить» у закрытого снимает
  `closedAt` (обычный тумбстоун, уйдёт через 90 дней), с undo.
- Суммы — `fmtH`; проценты доходности в приватном режиме не прячутся.
