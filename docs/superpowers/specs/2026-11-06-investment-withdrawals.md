# Инвестиции: вывод и исправление сумм

Согласовано: частичный вывод, вывод всей текущей стоимости с нулевым остатком, редактирование стоимости и сумм прошлых операций. История и доходность сохраняются.

Стоимость снимка абсолютна: он включает операции, уже существовавшие при его сохранении. Новые операции того же дня должны менять остаток сразу. Для этого рядом с числовыми snapshots хранится snapshotContribs — идентификаторы включённых операций той же даты. Старые снимки без метаданных сохраняют прежнюю семантику; перед первой правкой фиксируется их состав. Не угадывать порядок старых операций: уже неверный остаток пользователь может исправить снимком с нулём.

В выводе два режима: «Часть суммы» и «Вывести всё». Полный вывод берёт стоимость на выбранную дату; нельзя вывести больше доступного. Суммы сохраняются до копеек. В списках истории кнопки редактирования открывают существующие формы; при исправлении дата и банк операции сохраняются. Исправление операции с банковским переводом меняет существующий снимок банка только на разницу; при отсутствии снимка работает прежняя отложенная семантика.

Архитектура прежняя: весь JS и HTML в index.html, без новых зависимостей. Протокол Apps Script не меняется. Публикация и коммит не входят в задачу.
